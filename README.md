A deterministic Donchian-breakout paper-trading bot for Coinbase Wrapped BTC (cbBTC) on 1-minute bars: long-only, 60-bar breakout entries, 0.6% trailing stop, 60-bar max hold. $1,000 paper money, nothing traded for real.

## Run it

```sh
# Batches arrive as JSON lines on stdin; the bot answers with orders on stdout.
node main.ts < bars.jsonl
```
